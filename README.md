# MIDNIGHT VAULT

A top-down stealth heist game. You are Vesper, a thief crossing a bank vault room at
night: read the guards' sweeping vision cones, dodge the red CCTV cones, crack the gold
case, and run for the green EXIT before the alarm locks the building down.

Three rooms, each with several routes: sneak low past the planters or high along the
desks. Tools cost charges — lockpick cracks a vault instantly, EMP kills nearby cameras
for 8 seconds, smoke breaks every line of sight. Getting fully spotted starts a chase;
the alarm meter climbs, and at 100% the whole building hunts you. Grab the gold and the
getaway clock starts: 45 seconds to the EXIT. Finish a room without ever being spotted
for a ghost bonus.

Controls: WASD / arrows to move, SHIFT to sneak, 1 / 2 / 3 to pick a tool, SPACE to use
it, click anywhere to walk there. R retries a room.

Plays offline in a desktop browser: open `game/index.html` from any static server.
All art is drawn in code and all sounds are synthesized live with WebAudio — no files
are fetched. An original game by Vesper Works.
